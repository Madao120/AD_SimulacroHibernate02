## Ejercicio superheroes

### Tablas de la BD
    -- 1. Primero borramos la tabla dependiente (manga) y luego las demás
    DROP TABLE IF EXISTS superheroe;
    DROP TABLE IF EXISTS equipo;
    DROP TABLE IF EXISTS ciudad;
    
    -- Nota: En PostgreSQL no existe el comando USE.
    -- Debes asegurarte de estar conectado a la base de datos 'probas' antes de ejecutar el script.
    
    CREATE TABLE equipo (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    nome VARCHAR(255) NOT NULL,
    base VARCHAR(255) NOT NULL
    );
    
    CREATE TABLE ciudad (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    nome VARCHAR(255) NOT NULL,
    poboacion BIGINT NOT NULL,
    nivel_perigo INT NOT NULL
    );
    
    CREATE TABLE superheroe (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    nome VARCHAR(255) NOT NULL,
    nome_real VARCHAR(255) NOT NULL,
    poder VARCHAR(255) NOT NULL,
    
        equipo_id BIGINT NOT NULL,
        ciudad_id BIGINT NOT NULL UNIQUE,
    
        CONSTRAINT fk_superheroe_equipo
            FOREIGN KEY (equipo_id) REFERENCES equipo(id),
    
        CONSTRAINT fk_superheroe_ciudad
            FOREIGN KEY (ciudad_id) REFERENCES ciudad(id)
    );


### Enunciado del ejercicio
Configura Hibernate cambiando la IP.
En la clase Main, realiza las siguientes operaciones:
1. Crea tres ciudades: Nueva York, Gotham y Metropolis.
2. Crea dos equipos: Vengadores y Liga de la Justicia.
3. Crea tres superhéroes:

◦ Spiderman, perteneciente a los Vengadores y residente en Nueva York.

◦ Batman, perteneciente a la Liga de la Justicia y residente en Gotham.

◦ Superman, perteneciente a la Liga de la Justicia y residente en Metropolis.
4. Guarda las ciudades y los equipos en la base de datos.

5. Consulta y muestra todas las ciudades almacenadas.

6. Consulta y muestra todos los equipos junto con sus superhéroes.

7. Actualiza los datos de Gotham, cambiando su nombre, población y nivel de peligro.

8. Actualiza los datos de Spiderman, modificando su nombre, nombre real y poder.

9. Consulta y muestra nuevamente los equipos y sus superhéroes después de las modificaciones.

10. Elimina los registros restantes de ciudades y equipos.

11. Comprueba si quedan superhéroes en la base de datos y muestra:

12. Los superhéroes existentes, si los hay.

13. "No hay superheroes" cuando la lista resultante esté vacía.
